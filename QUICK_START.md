# Quick Download Guide

## ⚡ 3-Minute Setup

### Step 1: Download
```bash
git clone https://github.com/jlcv101-netizen/occuverse-ai.git
cd occuverse-ai
```

### Step 2: Install
```bash
npm install
```

### Step 3: Run
```bash
npm run dev
```

### Step 4: Open
Go to: **http://localhost:3000**

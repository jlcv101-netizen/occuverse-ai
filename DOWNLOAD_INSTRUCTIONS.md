# OccuVerse AI - Download & Installation Instructions\n\n## 📥 How to Download\n\n### Option 1: Clone with Git (Recommended)\n```bash\ngit clone https://github.com/jlcv101-netizen/occuverse-ai.git\ncd occuverse-ai\n```\n\n### Option 2: Download ZIP\n1. Go to: https://github.com/jlcv101-netizen/occuverse-ai\n2. Click **Code** → **Download ZIP**\n3. Extract the ZIP file\n4. Open terminal in the extracted folder\n\n---\n\n## 🚀 Installation & Setup\n\n### Step 1: Install Node.js (if not already installed)\n- Download from: https://nodejs.org/\n- Choose LTS version (recommended)\n- Install and verify:\n  ```bash\n  node --version\n  npm --version\n  ```\n\n### Step 2: Install Project Dependencies\n```bash\nnpm install\n```\nThis will install all required packages (Express, React, Axios, etc.)\n\n### Step 3: Setup Environment File\n```bash\ncp .env.example .env\n```\n\n### Step 4: Start the Application\n```bash\nnpm run dev\n```\n\n### Step 5: Access the App\n- **Frontend**: Open browser and go to `http://localhost:3000`\n- **Backend API**: `http://localhost:5000`\n\n---\n\n## ✨ What You Get\n\n✅ **AI Chat Assistant** - Real-time messaging  \n✅ **Profile Management** - User registration & login  \n✅ **Global Digital Clock** - 20+ time zones  \n✅ **Weather Dashboard** - Real-time weather data  \n✅ **Joke Generator** - Multiple joke categories  \n✅ **Responsive Design** - Works on all devices  \n✅ **Profile Picture Upload** - User avatars  \n\n---\n\n## 📊 Features by Tab\n\n| Tab | Feature | API Used |\n|-----|---------|----------|\n| 💬 Chat | AI messaging | Internal |\n| 👤 Profile | Upload picture | Internal |\n| 🕐 Clock | Multi-timezone clock | None (Local) |\n| 🌦️ Weather | Real-time weather | Open-Meteo (Free) |\n| 😂 Jokes | Random jokes | Official Joke API (Free) |\n| 🎨 Generate | Future features | Coming Soon |\n\n---\n\n## 🎮 How to Use Each Feature\n\n### Chat\n1. Click **💬 Chat** tab\n2. Type a message\n3. Click **Send**\n4. View message history\n\n### Profile\n1. Click **👤 Profile** tab\n2. See your profile info\n3. Click upload area or select file\n4. Choose an image\n5. Click **Upload Profile Picture**\n\n### Digital Clock\n1. Click **🕐 Clock** tab\n2. See 6 time zones with digital & analog clocks\n3. Click **+ Add Time Zone** to add more cities\n4. Click **✕** to remove a time zone\n\n### Weather\n1. Click **🌦️ Weather** tab\n2. Enter city name in search box\n3. Click **🔍 Search**\n4. View weather and 5-day forecast\n5. Click **°C / °F** to toggle temperature unit\n\n### Jokes\n1. Click **😂 Jokes** tab\n2. Select joke category from dropdown\n3. Click **🎲 Get Joke**\n4. Read and laugh!\n\n---\n\n## 🔧 Troubleshooting\n\n### Issue: \"npm: command not found\"\n**Solution:** Install Node.js from https://nodejs.org/\n\n### Issue: \"Port 3000 already in use\"\n**Solution:** \n```bash\n# Stop the process using port 3000 or change port in .env\nPORT=3001\n```\n\n### Issue: \"Cannot find module\"\n**Solution:**\n```bash\nrm -rf node_modules\nnpm install\n```\n\n### Issue: Weather not loading\n**Solution:** Check internet connection. Open-Meteo API is free and requires no key.\n\n### Issue: Profile upload not working\n**Solution:** Make sure public/uploads/profiles directory exists or restart the server.\n\n---\n\n## 📱 Accessing Remotely\n\n### Via Bolt (Already Configured)\n- Frontend: https://occuverse-ai-web-app-z7cu.bolt.host/\n- Just push to GitHub and Bolt handles the rest\n\n### On Same Network (Local)\n1. Find your computer's IP: `ipconfig` (Windows) or `ifconfig` (Mac/Linux)\n2. Access from phone/tablet: `http://YOUR_IP:3000`\n\n---\n\n## 🌐 Deploy to Production\n\n### Vercel (Frontend)\n1. Create account at https://vercel.com\n2. Connect GitHub repo\n3. Deploy with one click\n\n### Heroku (Backend)\n1. Create account at https://www.heroku.com\n2. Install Heroku CLI\n3.

# 🚀 OccuVerse AI - Complete Setup Guide\n\n## Quick Start\n\n### 1. Clone the Repository\n```bash\ngit clone https://github.com/jlcv101-netizen/occuverse-ai.git\ncd occuverse-ai\n```\n\n### 2. Install Dependencies\n```bash\nnpm install\n```\n\n### 3. Create Environment File\n```bash\ncp .env.example .env\n```\n\n### 4. Run the Application\n\n**Development Mode (Recommended for local testing):**\n```bash\nnpm run dev\n```\n\nThis starts both:\n- Backend Server: `http://localhost:5000`\n- Frontend App: `http://localhost:3000`\n\n**Production Build:**\n```bash\nnpm run build\nnpm start\n```\n\n---\n\n## 🎯 Features Overview\n\n### 💬 AI Chat Assistant\n- Real-time messaging interface\n- Message history\n- Responsive design\n- Ready for AI API integration (OpenAI, Claude, etc.)\n\n### 👤 Profile Management\n- User registration & login (Mock Auth)\n- Profile picture upload (FIXED & WORKING ✅)\n- User profile display\n- Secure password hashing\n\n### 🕐 Global Digital Clock\n- Real-time time display\n- 20+ popular time zones\n- Add/Remove custom time zones\n- Digital & Analog clock visualization\n- UTC offset display\n- Smooth animations\n\n### 🌦️ Weather Dashboard\n- Real-time weather data (Open-Meteo API)\n- Search weather by city\n- 5-day forecast\n- Temperature unit toggle (°C/°F)\n- Detailed weather metrics:\n  - Humidity, Wind Speed, Pressure\n  - Visibility, Cloud Cover\n  - Sunrise/Sunset times\n- Beautiful weather icons\n\n### 😂 Joke Generator\n- Random jokes via Official Joke API\n- Multiple categories:\n  - Random\n  - Programming\n  - General\n  - Knock-knock\n- Beautiful animated display\n- Setup & punchline separation\n- Category badges\n\n---\n\n## 📁 Project Structure\n\n```\noccuverse-ai/\n├── server.js                 # Express backend server\n├── package.json             # Dependencies & scripts\n├── .env.example             # Environment template\n├── .gitignore              # Git ignore rules\n├── bolt.json               # Bolt deployment config\n│\n├── pages/\n│   └── index.jsx           # Main home page with tabs\n│\n├── components/\n│   ├── Chat.jsx            # Chat interface\n│   ├── ProfileUpload.jsx   # Profile picture upload\n│   ├── DigitalClock.jsx    # Multi-timezone clock\n│   ├── WeatherDashboard.jsx # Weather information\n│   └── JokeGenerator.jsx   # Joke fetcher\n│\n├── public/\n│   └── uploads/            # Profile pictures storage\n│\n└── README.md               # Documentation\n```\n\n---\n\n## 🔌 API Endpoints\n\n### Authentication\n```\nPOST /api/auth/register     # Register new user\nPOST /api/auth/login        # Login user\n```\n\n### Profile\n```\nPOST /api/profile/upload    # Upload profile picture\nGET  /api/profile/:email    # Get user profile\n```\n\n### Chat\n```\nPOST /api/chat              # Send message\nGET  /api/chat/:userId      # Get chat history\n```\n\n### External Data\n```\nGET  /api/weather?city=London&unit=metric\nGET  /api/jokes/random?type=programming\n```\n\n---\n\n## 🛠️ Technology Stack\n\n### Backend\n- **Node.js** - Runtime\n- **Express.js** - Web framework\n- **Multer** - File upload handling\n- **bcryptjs** - Password hashing\n- **jsonwebtoken** - JWT authentication\n- **axios** - HTTP client\n- **CORS** - Cross-origin support\n\n### Frontend\n- **React** - UI library\n- **Next.js** - React framework\n- **Axios** - API calls\n- **CSS-in-JS** - Styled JSX\n\n### External APIs\n- **Open-Meteo** - Weather data (free, no API key)\n- **Official Joke API** - Jokes (free, no API key)\n- **Geocoding API** - City coordinates\n\n---\n\n## ⚙️ Environment Variables\n\nEdit `.env` file:\n\n```\nPORT=5000                              # Server port\nJWT_SECRET=your-secret-key-here        # JWT signing key\nNODE_ENV=development                   # Environment mode\nAPI_BASE_URL=http://localhost:5000     # Backend URL\nNEXT_PUBLIC_API_URL=http://localhost:5000  # Public API URL\n```\n\n---\n\n## 🚀 Deployment Options\n\n### Bolt.new (Already Configured)\n```bash\ngit push origin main\n# Connect repo to Bolt in dashboard\n```\n\n### Vercel (Frontend) + Heroku (Backend)\n1. Push to GitHub\n2. Connect to Vercel (frontend)\n3. Connect to Heroku (backend)\n\n### Docker\n```dockerfile\nFROM node:16\nWORKDIR /app\nCOPY . .\nRUN npm install\nEXPOSE 5000\nCMD [\"npm\", \"start\"]\n```\n\n---\n\n## 🔧 Common Commands\n\n```bash\n# Install dependencies\nnpm install\n\n# Start development server\nnpm run dev\n\n# Build for production\nnpm run build\n\n# Start production server\nnpm start\n\n# Run frontend only\nnpm run client\n\n# Run backend only\nnpm run server\n```\n\n---\n\n## 📝 Next Steps / Roadmap\n\n- [ ] Integrate real AI APIs (OpenAI, Claude)\n- [ ] Add database (MongoDB/PostgreSQL)\n- [ ] Real-time notifications\n- [ ] Advanced code execution sandbox\n- [ ] Team collaboration features\n- [ ] Mobile app version\n- [ ] Dark mode\n- [ ] Internationalization (i18n)\n\n---\n\n## 🐛 Troubleshooting\n\n### Port Already in Use\n```bash\n# Change port in .env\nPORT=5001\n```\n\n### Module Not Found\n```bash\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n### CORS Errors\n- Check API_BASE_URL in .env\n- Verify backend is running on correct port\n\n### Weather API Not Working\n- Open-Meteo API is free and requires no key\n- Check internet connection\n- Verify city name spelling\n\n---\n\n## 📧 Support\n\nFor issues or questions:\n- GitHub Issues: https://github.com/jlcv101-netizen/occuverse-ai/issues\n- Email: jhonlordvisto101@gmail.com\n\n---\n\n## 📄 License\n\nMIT License - Free for personal and commercial use\n\n---\n\n## 🎉 Credits\n\nBuilt with ❤️ by OccuVerse Team\n\nExternal APIs:\n- Weather: Open-Meteo\n- Jokes: Official Joke API\n- Geocoding: Open-Meteo Geocoding\n\n---\n\n**Happy Coding! 🚀**\n
